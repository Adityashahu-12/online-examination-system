  • 1. Department registers academic profile & coordinators.
  • 2. Faculty lists exam with subject, duration & format.
  • 3. Admin validates schedules & checks center conflicts.
  • 4. Approved exams appear on live public notice board.

Standby Status: The web interface has been built using pure HTML5, CSS3, and modern JavaScript. It is fully operational with simulated client state, in-memory validation, and localStorage persistence.

-- Schema Target: PostgreSQL 16 + btree_gist
1. USERS (user_id, full_name, email, password_hash, role)
2. DEPARTMENTS (department_id, department_name, contact, email)
3. SUBJECTS (subject_id, subject_name, description)
4. EXAM_CENTERS (center_id, center_name, center_type, status)
5. EXAMS (exam_id, title, description, duration_minutes)
6. SCHEDULES (schedule_id, exam_id, center_id, date, start_time, end_time)
Exclusion: no_overlap EXCLUDE USING gist (center_id WITH =, daterange WITH &&)
